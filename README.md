# Brockway Rovers Football iOS App

Official iOS project for the Brockway Rovers Football app.

- App Store name: Brockway Rovers Football
- Bundle ID: `com.brockwayrovers.football`
- Version: 1.0
- Build: 1
- iPhone target

The initial release provides a native iOS shell for the Brockway Rovers mobile web experience. The project uses SwiftUI and WKWebView and is prepared for Apple automatic code signing.

## Build preparation

This repository uses `project.yml` as the XcodeGen project specification. On a macOS build environment with XcodeGen installed, run `xcodegen generate` to create `BrockwayRoversFootball.xcodeproj` before building/archive.
